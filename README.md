# 🚀 API de Cadastro de Usuários (Spring Boot + Vanilla JS)

<img src="https://img.shields.io/badge/Status-Concluído-success?style=for-the-badge" alt="Status" /> <img src="https://img.shields.io/badge/Backend-Java%20Spring-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white" alt="Java" /> <img src="https://img.shields.io/badge/Frontend-Vanilla%20JS-F7DF1E?style=for-the-badge&logo=javascript&logoColor=black" alt="JavaScript" />



Este projeto é uma aplicação **Full Stack** completa, que permite o cadastro e a listagem de usuários em tempo real. O sistema utiliza um backend robusto em Java com Spring Boot e um frontend leve construído com tecnologias web puras.

---

## 🚀 Progresso e Funcionalidades
- [x] **Backend:** Criação de Endpoints REST com Spring Boot.
- [x] **Frontend:** Interface responsiva com HTML5 e CSS3.
- [x] **Integração:** Consumo da API utilizando **Fetch API** do JavaScript.
- [x] **Persistência:** Gerenciamento de dados e lógica de negócio.

## 🛠️ Tecnologias Utilizadas
* **Backend:** Java 17+ (Compatível com Java 25), Spring Boot 3.2.2.
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla).
* **Dependências:** Maven.
* **Ferramentas:** VS Code / IntelliJ IDEA.

---

## 🏗️ Estrutura do Projeto
O projeto segue a estrutura padrão do Maven para garantir a organização e escalabilidade do código:

- `src/main/java`: Contém a lógica do backend (Controllers, Services e Models).
- `index.html`: Interface do usuário que se comunica com a API.
- `pom.xml`: Configurações e dependências do projeto.

---

## 🚀 Como Executar a Aplicação

### 1. Backend (Java)
1. Certifique-se de ter o JDK 17+ instalado.
2. Abra o projeto na sua IDE de preferência.
3. Execute a classe principal em `src/main/java/Main.java`.

### 2. Frontend (Web)
1. Abra o arquivo `index.html` no navegador ou via **Live Server** no VS Code.
2. Preencha os campos e utilize a integração em tempo real.
